# BankSim dataset attribution and license

This project uses the synthetic transaction dataset commonly known as BankSim, specifically `bs140513_032310.csv`.

- **Dataset source:** [BankSim on Kaggle (NTNU TESTIMON)](https://www.kaggle.com/ntnu-testimon/banksim1)
- **Dataset type:** Synthetic financial-payment transactions generated for research; it is not a real bank's raw transaction ledger.
- **License reported by the dataset source:** Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (CC BY-NC-SA 4.0).
- **Original work:** Edgar Alonso Lopez-Rojas and Stefan Axelsson, “BankSim: A Bank Payments Simulator for Fraud Detection Research,” EMSS 2014.
